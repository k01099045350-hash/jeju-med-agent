제주 읍면동별 진료과목 분포 비교 Agent - 실행 방법

1. 압축을 원하는 폴더에 풉니다. 설치는 필요 없습니다. 자세한 내용은 README.md, docs 폴더의 PDF를 보세요.
2. run.bat 을 더블클릭합니다.
   - 검은 창이 뜨고 1초 뒤 브라우저(크롬/엣지)가 자동으로 열립니다.
   - 브라우저가 안 열리면 주소창에 http://127.0.0.1:8765 를 입력하세요.
3. 질문 칸에 "한경면에 소아청소년과 있어?"처럼 입력하고 [물어보기]를 누릅니다.
   (범위 안 9곳 · 등록 확인 3곳 · 과목 정보 없음 6곳이 나오면 정상)
4. 끝낼 때는 검은 창을 닫습니다.

- 인터넷과 API 키가 없어도 모든 기능이 동작합니다.
- (선택) 질문 해석 보조 LLM을 쓰려면 환경변수 ANTHROPIC_API_KEY 또는 OPENAI_API_KEY 를 설정하거나,
  '평가용_API키.txt'에 키를 적고 다시 실행하세요. LLM은 질문 문장을 다시 쓰는 데만 쓰이고, 숫자는 항상 프로그램이 계산합니다.
- 결과 화면의 지도는 인터넷 지도가 아니라 프로그램에 들어 있는 경계 자료로 그립니다(인터넷 불필요).
  병원 위치는 건강보험심사평가원 자료와 기관명·도로명주소가 일치한 시설만 찍습니다. 출처: jeju_med\data\출처와_라이선스.txt
- 함께 들어 있는 python 폴더: 설치 없이 실행되는 Python 3.12.12 (python-build-standalone, Windows x64).
- 동작 확인: python\python.exe jeju_med\tests\test_questions.py  →  ALL PASS
